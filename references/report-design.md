# Report Design Guidance

When the environment supports document/PDF generation, render the final report with restrained professional assurance styling:

- A4/Letter friendly margins and page breaks;
- neutral sans-serif body typography and strong heading hierarchy;
- cover page with application, assessment period, CASA version and confidentiality classification;
- repeating footer with report title/version and page number;
- compact KPI/result table, not decorative dashboard cards;
- finding callouts that emphasize rating, CASA criteria and status without excessive color;
- tables that repeat headers across pages;
- appendices for detailed matrices/evidence rather than overcrowding the executive section;
- no third-party professional-services logos, trademarks or visual imitation that implies affiliation.

The visual quality may resemble a mature external assurance report, but branding must remain the project/developer's own.
