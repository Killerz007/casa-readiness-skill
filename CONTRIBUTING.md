# Contributing

Changes to assessment logic should be evidence-based and traceable to authoritative sources.

For CASA criteria changes:

1. link the relevant App Defense Alliance release/commit;
2. update or regenerate the upstream manifest/catalogue;
3. update affected test/scanner mappings;
4. add/update parser validation tests;
5. explain any changed readiness conclusion logic;
6. do not weaken evidence requirements merely to reduce findings.

Upstream CASA material retains its upstream CC BY-SA 4.0 licensing.
